REGRAS PARA AS VARIAVEIS: Identificadores

- Podem começar com letra, $ ou _
- É possivel usar letras e numeros
- É possivel usar acentos e símbolos

- NÃO podem começar com números
- NÃO podem conter espaços
- NÃO podem ser palavras reservadas (Palavaras que o JS use ex:alert)

---------------------------------------------------------------------
DICAS PARA BOAS PRATICAS:

- Maiúsculas e minusculas fazem diferença (A e a são diferentes)
- Tente escolher nomes coerentes para as variáveis
